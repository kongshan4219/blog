# SeaweedFS `weed master` 命令参数说明

本文档完整保留 `weed master -help`​ 命令的**英文原文**，并补充**中文翻译**，方便查阅使用。

## 命令示例 (Example)

**原文**：Example: weed master -port=9333  
**翻译**：示例：weed master -port=9333

## 功能描述 (Description)

**原文**：  
start a master server to provide volume=>location mapping service and sequence number of file ids

The configuration file "security.toml" is read from ".", "$HOME/.seaweedfs/", "/usr/local/etc/seaweedfs/", or "/etc/seaweedfs/", in that order.

The example security.toml configuration file can be generated by "weed scaffold -config=security"

For single-master setups, use -peers=none to skip Raft quorum wait and enable instant startup.  
This is ideal for development or standalone deployments.

License file loading order:

1. -license flag path (if provided)
2. SEAWEED_LICENSE environment variable (if set)
3. Standard locations: "./seaweed-license.json", "$HOME/.seaweedfs/seaweed-license.json", "/usr/local/etc/seaweedfs/seaweed-license.json", "/etc/seaweedfs/seaweed-license.json"

**翻译**：  
启动主节点服务，提供**卷-存储位置映射**服务和文件ID序列号分配服务。

程序会按以下顺序读取`security.toml`​安全配置文件：  
当前目录 → 用户家目录下的`.seaweedfs/`​ → `/usr/local/etc/seaweedfs/`​ → `/etc/seaweedfs/`

可通过命令 `weed scaffold -config=security`​ 生成`security.toml`配置文件示例。

**单主节点部署**：使用`-peers=none`参数可跳过Raft集群一致性等待，实现秒级启动；  
该模式适用于开发环境或单机部署场景。

许可证文件加载优先级：

1. ​`-license`参数指定的路径（若配置）
2. ​`SEAWEED_LICENSE`环境变量（若配置）
3. 标准路径：`./seaweed-license.json`​ → `$HOME/.seaweedfs/seaweed-license.json`​ → `/usr/local/etc/seaweedfs/seaweed-license.json`​ → `/etc/seaweedfs/seaweed-license.json`
