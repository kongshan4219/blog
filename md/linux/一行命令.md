### 1. **下载GitHub最新Release资产**

```bash
USERNAME="username" REPO="repo" TOKEN="git-access-token" ASSET_NAME="filename" DEST_DIR="out-path"; mkdir -p "$DEST_DIR" && ASSET_ID=$(curl -s -H "Authorization: token $TOKEN" "https://api.github.com/repos/$USERNAME/$REPO/releases/latest" | jq -r --arg ASSET_NAME "$ASSET_NAME" '.assets[] | select(.name == $ASSET_NAME) | .id') && curl -LJ -o "$DEST_DIR/$ASSET_NAME" -H "Authorization: token $TOKEN" -H "Accept: application/octet-stream" "https://api.github.com/repos/$USERNAME/$REPO/releases/assets/$ASSET_ID"
```

#### 可选参数：

- ​`-s`​ (简化模式)：使`curl`输出静默，即不显示进度条和错误信息。适合自动化脚本使用。
- ​`-L`​ (重定向跟随)：如果请求的URL发生重定向（例如HTTP 301或302），`curl`会自动跟随重定向。
- ​`-J`​ (自动保存为文件)：如果服务器返回了一个`Content-Disposition`​头，`curl`会自动使用这个头部中的文件名保存下载的内容。

### 2. **挂载Windows共享目录到Linux**

```bash
sudo mount -t cifs -o username=linux,password=linux,uid=1000,gid=1000 //192.168.10.253/debian-share /mnt/windows
```

#### 可选参数：

- ​`-t cifs`​：指定文件系统类型为CIFS，用于Windows共享。若没有指定，`mount`会尝试自动检测文件系统类型。
- ​`-o`：设置挂载选项。可以组合多个选项，常见的包括：

  - ​`username=<user>`：指定登录Windows共享的用户名。
  - ​`[已脱敏-密码]
  - ​`uid=<UID>`：指定挂载后文件的用户ID，通常用于设置文件的所有者。
  - ​`gid=<GID>`：指定挂载后文件的组ID。
  - ​`file_mode=<mode>`​：设置文件的权限模式，例如`0666`。
  - ​`dir_mode=<mode>`​：设置目录的权限模式，例如`0777`。
  - ​`vers=<version>`​：指定CIFS协议的版本。例如，`vers=3.0`指定使用CIFS 3.0协议。

### 3. **使用rsync同步文件，带锁**

```bash
#!/bin/bash

LOCKFILE="/tmp/rsync.lock"

flock -n -E 1 $LOCKFILE -c "rsync -avzP --bwlimit=2048 --delete ubuntu@1.1.1.1:/var/discourse/shared/standalone/backups/default/ /data/backups/ld/"
```

#### 可选参数：

- ​`-a`​ (归档模式)：这个选项启用递归和保持文件属性（如权限、时间戳和符号链接等），相当于`-rlptgoD`。
- ​`-v` (详细输出)：显示更多的输出信息，包括文件同步的详细过程。
- ​`-z` (压缩传输)：在传输文件时启用压缩，减少带宽消耗，适合远程传输。
- ​`-P`​ (显示进度并保持部分传输)：类似`-v`，但提供更详细的进度信息，并支持部分传输恢复。
- ​`--bwlimit=<limit>`​：限制带宽使用量，单位为KB/s。例如，`--bwlimit=2048`将带宽限制为2048KB/s。
- ​`--delete`：删除目标目录中那些源目录中不存在的文件，通常用于镜像备份。

### 4. **通过SSH远程端口转发**

```bash
ssh -R 4000:localhost:22 user@ip
```

#### 可选参数：

- ​`-R`​ (远程端口转发)：将远程主机的端口转发到本地主机上的某个端口。语法为`-R <远程端口>:<本地地址>:<本地端口>`。

  - ​`4000`：远程主机上可访问的端口。
  - ​`localhost:22`：本地机器上的目标端口和地址。
- ​`-L`​ (本地端口转发)：与`-R`相反，将本地端口映射到远程主机。
- ​`-N` (不执行命令)：连接后不执行任何命令，只进行端口转发。
- ​`-f`​ (后台运行)：使SSH会话在后台运行，通常与`-N`配合使用。
- ​`-C` (压缩)：启用压缩，使传输更加高效。

### 5. **删除端口代理**

```bash
netsh interface portproxy delete v4tov4 listenport=6379 listenaddress=127.0.0.1
```

#### 可选参数：

- ​`listenport=<port>`：指定监听的端口号。
- ​`listenaddress=<address>`​：指定监听的地址。可以是`0.0.0.0`​（监听所有地址），也可以指定为某个具体地址（如`127.0.0.1`）。
- ​`v4tov4`​：IPv4到IPv4的端口代理。也可以指定`v6tov6`进行IPv6到IPv6的代理。

### 6. **添加端口代理**

```bash
netsh interface portproxy add v4tov4 listenport=6379 listenaddress=127.0.0.1 connectport=6379 connectaddress=192.168.1.19
```

#### 可选参数：

- ​`listenport=<port>`：指定本地监听的端口号。
- ​`listenaddress=<address>`：指定本地监听的地址。
- ​`connectport=<port>`：指定远程服务器上的端口号。
- ​`connectaddress=<address>`：指定远程服务器的IP地址或主机名。
- ​`v4tov4`：指定端口代理的协议类型，表示从一个IPv4地址到另一个IPv4地址的代理。
