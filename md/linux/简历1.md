###### 视频网站系统

技术栈：SpringBoot、Mybatis-Plus、MySQL、Redis、rabbitMq、Spring Security
项目简介：项目包含前台网站和后台管理系统两个部分。实现了单点登录、视频搜索、签到、点赞关注、视频上传、分片播放等功能
• 使用 Redis+Token 机制实现单点登录
• 通过对视频切片后上传，减小服务器压力,上传完所有切片后通过多线程进行合并，并通过 FFmpeg 生成m3u8索引个 ts 切片，实现视频分段加载
• 视频文件上传前进行 md 5校验，防止重复上传，上传后通过 md 5值生成视频文件唯一标识，存储文件信息
• 使用map对分片播放的视频进行统一管理，实现多人同时播放同一视频的同一片段时，只会读取文件到堆内存中一次， 从而节省了内存开销，并且提升了多人同时播放视频时的加载速度
• 对 Redis 所有缓存 key 设置N+n的过期时间，从而合理使用内存并防止缓存雪崩
• 使用 RedisBitMap 实现用户连续签到统计功能，节约了数据库内存
• 使用 RedisSet 数据结构实现用户关注、共同关注功能

###### 校园互助小程序

技术栈：Spring Boot+MyBatis(Plus)+MySQL+Redis+rabbitMq+websocket+uni-app
项目简介：搭建一个校园互助平台，使校内师生能够更轻松、高效地获取并提供互助服务，实现发布互助信息、响应互助信息、私信、排行榜等核心功能
• 使用 websocket 实现私信信息实时推送,并且展示未读私信数量
• 使用 rabbitMq 死信队列及消息过期机制实现长时间无人响应的互助信息自动取消
• 使用双重锁校验防止用户重复响应互助信息，保证一个互助信息只允许一人响应
