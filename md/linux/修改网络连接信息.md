从你的配置文件来看，当前网线连接对应的网卡是 `enp1s0`​，但目前它使用的是 `dhcp4: true`​（自动获取IP和DNS）。如果你想为网线连接（`enp1s0`）指定DNS服务器，可以按以下步骤修改配置：

### 步骤1：编辑netplan配置文件

```bash
sudo vim /etc/netplan/50-cloud-init.yaml
```

### 步骤2：修改`enp1s0`的配置（添加指定DNS）

找到 `ethernets`​ 下的 `enp1s0`​ 部分，添加 `nameservers` 配置。如果希望保持DHCP自动获取IP，但强制指定DNS，可以这样改：

```yaml
network:
  version: 2
  renderer: NetworkManager
  
  ethernets:
    enp1s0:
      dhcp4: true        # 保持DHCP自动获取IP
      optional: true
      nameservers:       # 添加这部分指定DNS
        addresses:
          - 114.114.114.114  # 首选DNS
          - 8.8.8.8          # 备用DNS（可替换为你需要的DNS）
      
  wifis:
    wlo1:
      dhcp4: false
      addresses:
        - 192.168.10.254/24
      gateway4: 192.168.10.1
      nameservers:
        addresses:
          - 114.114.114.114
          - 8.8.8.8
      access-points:
        "406-5G":
          password: "fgf816516"
```

> 注意：yaml文件对缩进非常敏感，确保 `nameservers`​ 与 `dhcp4` 同级（缩进一致）。

### 步骤3：如果需要固定IP（可选）

如果想让网线连接使用固定IP而非DHCP，可以将 `dhcp4: true`​ 改为 `false`，并手动指定IP、网关和DNS：

```yaml
ethernets:
  enp1s0:
    dhcp4: false
    addresses:
      - 192.168.254.x/24  # 替换为你的固定IP（如192.168.254.100）
    gateway4: 192.168.254.1  # 替换为你的网关IP
    nameservers:
      addresses:
        - 114.114.114.114  # 指定DNS
        - 8.8.8.8
```

### 步骤4：应用配置

修改后执行以下命令使配置生效：

```bash
sudo netplan apply
```

### 验证配置

检查网线连接的DNS是否生效：

```bash
# 查看当前DNS配置
systemd-resolve --status enp1s0 | grep "DNS Servers"

# 用指定网卡解析域名测试
dig @enp1s0 kongseek.com
```

这样，网线连接（`enp1s0`）就会使用你指定的DNS服务器解析域名了。
