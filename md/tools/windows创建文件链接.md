# windows创建文件链接

在Windows中，可以使用符号链接（Symbolic Link）来实现你所描述的效果。具体步骤如下：

1. **打开命令提示符**：

   - 按下 `Win + R`，输入 `cmd`，然后按下 `Enter`。
2. **使用mklink命令创建符号链接**：

   - 输入以下命令并按下 `Enter`：

     ```bash
     mklink /D "D:\User\yaoye\OneDrive\zexu_orgin" "E:\zexu"
     ```
   - 这里，`/D` 表示创建一个目录链接。如果你想创建文件链接，则不需要 `/D`。
3. **检查链接**：

   - 打开 `D:\User\yaoye\OneDrive`，查看其中的内容是否与 `E:\test` 相同。

## 注意事项：

- 确保你有足够的权限来创建符号链接（管理员权限）。
- 如果 `D:\User\yaoye\OneDrive` 目录已存在，需先删除或重命名它。

完成以上步骤后，`D:\User\yaoye\OneDrive` 的内容将与 `E:\test` 同步。

要删除Windows中的符号链接，可以按照以下步骤进行：

1. **打开命令提示符**：

   - 按下 `Win + R`，输入 `cmd`，然后按下 `Enter`。
2. **使用del命令删除链接**：

   - 输入以下命令并按下 `Enter`：

     ```bash
     rmdir "D:\User\yaoye\OneDrive"
     ```
   - 这里使用 `rmdir` 命令是因为符号链接是一个目录类型的链接。如果你创建的是文件链接，使用 `del` 命令。
3. **检查确认**：

   - 进入 `D:\User\yaoye` 目录，确保 `OneDrive` 链接已被删除。

## 注意事项：

- 确保在删除链接之前，了解这不会删除 `E:\test` 目录的内容，只会删除链接本身。
