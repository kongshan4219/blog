# 名词解释

## 改包销售

有两种情况：

- 一种以大单位作为库存单位和主销售单位，允许拆零销售。如烟。
- 一种以小单位作为库存单位和主销售单位，允许按进货单位整包销售。如整箱牛奶。

举例说明：

1. 某烟，按条管理库存，前台有拆成包出售。

   - 建商品基本资料：货号01，X烟（条），定进价、售价。
   - 建商品基本资料：货号02，X烟（盒），定售价、进价，商品类型选“捆绑商品”；
   - 在“组合商品”中输入X烟（盒）02的“成分商品编码”为01和“成分数量”为0.1；
   - 进货和后台库存业务只允许操作01，按条管理库存
   - 前台销售可以同时销售01和02，销售的一盒02，在日结时将自动转化为0.1盒01出库。
2. 某牛奶，按盒管理库存，前台有按箱出售。

   - 建商品基本资料：货号001，牛奶（盒），定进价、售价。
   - 建商品基本资料：货号002，牛奶（箱），定售价、进价，商品类型选“捆绑商品”；
   - 在“组合商品”中输入牛奶（箱）002的“成分商品编码”为001和“成分数量”为24；
   - 进货和后台库存业务只允许操作001，按盒管理库存
   - 前台销售可以同时销售001和002，销售的一箱002，在日结时将自动转化为24盒001出库。

## 捆绑促销

捆绑促销：用于打包销售的商品如礼篮。
捆绑商品不维护库存，不允许作采购入库，必须在“组合商品”指定该商品的成分商品。
例：礼篮

1. 建商品基本资料：货号01，礼篮，定售价，商品类型选“捆绑商品”；
2. 在“组合商品”中为01商品指定其组成成份，输入：
   - X烟， “成分商品编码”为02，“成分数量”为1(条)；
   - Y酒，“成分商品编码”为03，“成分数量”为1(瓶)
   - Z水果，“成分商品编码”为04，“成分数量”为2(斤)
3. 前台销售01礼篮，每销售的一个礼篮，在日结时将自动转化为1条X烟，1瓶Y酒，2斤Z水果出库。

说明：

- 01礼篮不必做电脑系统的出入库操作，始终保持零库存。
- 01的售价按成份的售价和数量比例摊分到每一个成份商品上。
